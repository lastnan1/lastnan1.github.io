## 可复现 Idea

### Idea 1：AMAW 式「重采样 + NLL 调 λ」

- **思路**：每 N 步按 PDE 残差移动 20% 配点，并用 NLL 更新 λ_PDE/λ_S/λ_BC。
- **关键改动**：相对 [[2026-06-04/01-BRDR-平衡残差衰减率]] 只调权不动点。
- **首个实验**：2D 声波均匀模型；对比固定配点 + C 方案。
- **参考**：[[01-AMAW-PINN-配点与损失联合自适应]]
- **风险**：重采样与 FD 参考网格对齐要小心。

### Idea 2：快照配点 SA-PINN minimax

- **思路**：在 80×80 快照网格上为每点学 λ_S，min 网络 max λ（仅 L_S）。
- **关键改动**：相对 [[2026-06-04/02-LA-PINN-损失注意力]] 不用 LAN，用 minimax。
- **首个实验**：层状模型；看反射区权重热力图。
- **参考**：[[02-SA-PINN-极小极大点级权重]]
- **风险**：max λ 步需较小学习率防振荡。

### Idea 3：gPINN 梯度项 + ReLoBRaLo 项权

- **思路**：损失 = ReLoBRaLo 平衡的 (L_PDE, L_S, L_BC) + α·||∇_{x,z,t} r_PDE||²。
- **关键改动**：在 [[2026-06-04/04-ReLoBRaLo-相对损失平衡]] 上加物理梯度项而非新 λ 方案。
- **首个实验**：Burgers 1D 先验验证再移植声波。
- **参考**：[[03-gPINN-梯度增强损失]]、[[2026-06-04/04-ReLoBRaLo-相对损失平衡]]
- **风险**：梯度项计算增加 autograd 开销。

### 可复现 Idea（第 2 批）

#### Idea 4：ConFIG 伪逆方向 + C 方案 λ 联合
- **思路**：用 ConFIG 伪逆更新方向替换 Adam 默认方向，同时保留 C 方案 `RelativeProgressLambdaWeights` 动态调 λ。
- **关键改动**：相对 [[2026-06-04/01-BRDR-平衡残差衰减率]] 从「幅值加权」改为「方向无冲突」。
- **首个实验**：2D 声波正演；对比 baseline Adam + ConFIG + C 方案的三条曲线。
- **参考**：[[04-ConFIG-无冲突梯度训练]]
- **风险**：伪逆计算随 θ 维度增大开销明显，需评估性价比。

#### Idea 5：快照硬约束嵌入
- **思路**：将 L_S（FD 快照约束）改为硬约束嵌入到网络输出层，L_PDE / L_BC 仅保留软损失，消除快照梯度对 PDE 项的干扰。
- **关键改动**：相对 [[05-WHC-PINN-双曲守恒律加权]] 从激波 BC 硬约束迁移到 PINN 快照数据硬约束。
- **首个实验**：均匀模型；对比快照软惩罚 vs 硬嵌入的 L_PDE 下降曲线。
- **参考**：[[05-WHC-PINN-双曲守恒律加权]]
- **风险**：输出层改造与 FD 网格对齐较复杂。

#### Idea 6：PD 框架替换 λ 更新规则
- **思路**：以对偶上升（`λ_k ← λ_k + η_λ · L_k`）替换 C 方案的 `RelativeProgressLambdaWeights`，在单次迭代中同步更新 θ 和 λ。
- **关键改动**：相对 [[2026-06-04/07-AL-PINN-增广拉格朗日]] 无二次惩罚项，更轻量。
- **首个实验**：2D 声波；对比 C 方案 λ 轨迹 vs PD 对偶上升 λ 轨迹。
- **参考**：[[06-PD-PINN-原始对偶鲁棒训练]]、[[2026-06-04/07-AL-PINN-增广拉格朗日]]
- **风险**：dual ascent 步长 η_λ 需仔细调节，过大可能震荡。
