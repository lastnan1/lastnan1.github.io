## 可复现 Idea

### Idea 1：BRDR + 声波正演三分项点级权重

- **思路**：在 2D 声波 PINN 上对 PDE 配点用 BRDR 动态权，缓解 PDE loss 过大。
- **关键改动**：相对现有 C 方案（梯度模长 + Sigmoid λ），改为残差衰减率平衡。
- **首个实验**：均匀介质 + Ricker；对比固定 λ 与 C 方案；指标 L2@0.04/0.06/0.12 s、权重热力图。
- **参考**：[[01-BRDR-平衡残差衰减率]]
- **风险 / 难度**：配点历史残差存储；mini-batch 实现略复杂。

### Idea 2：快照 LAN（仅 L_S）

- **思路**：轻量 LAN 只接双快照损失，强化波前/反射区。
- **关键改动**：相对 [[02-LA-PINN-损失注意力]] 全文，先不动 PDE 项。
- **首个实验**：层状速度模型；对比 B 方案（Tanh-ELU + λ_PDE）。
- **风险 / 难度**：对抗训练可能振荡。

### Idea 3：DB 式 inter/intra 移植到 λ_PDE / λ_S / λ_BC

- **思路**：三项损失 MOO + 鲁棒权重更新，替换 C 方案初始化。
- **关键改动**：相对 [[03-DB-PINN-双层次平衡]]，接入 `trainers.py`。
- **首个实验**：`run_experiment.py` A/B/C 同域对比。
- **风险 / 难度**：梯度统计开销高于 ReLoBRaLo。

### 可复现 Idea（10 个）

#### Idea 4：ReLoBRaLo 接入三分项损失
- **思路**：用相对损失进展自动缩放 λ_PDE/λ_S/λ_BC，零梯度统计开销。
- **参考**：[[04-ReLoBRaLo-相对损失平衡]]、[[01-BRDR-平衡残差衰减率]]
- **实验**：`run_experiment.py` 增加 `train_relobralo()`；对比 C 方案。
- **风险**：对初始 loss 尺度敏感，需 warm-up。

#### Idea 5：NTK 初始化 + 可学习 λ 微调
- **思路**：训练前用 NTK 特征值定 λ 初值，再跑现有 C 方案联合优化。
- **参考**：[[05-NTK-特征值加权]]、[[03-DB-PINN-双层次平衡]]
- **实验**：均匀声波模型；记录初值 vs 手工 (0.7,1,0.1)。
- **风险**：NTK 估计成本（可每 500 步更新一次）。

#### Idea 6：PDE 配点 RBA 掩码
- **思路**：仅对 PDE 残差配点用 RBA 累积残差权，快照/BC 保持项级 λ。
- **参考**：[[06-RBA-残差注意力]]、[[13-vRBA-变分残差注意力]]
- **实验**：层状模型；对比 BRDR（[[01-BRDR-平衡残差衰减率]]）。
- **风险**：与 mini-batch 采样需维护残差缓存。

#### Idea 7：AL-PINN 乘子替代 Sigmoid λ
- **思路**：BC/IC/快照视为约束，用 ALM 更新乘子而非 `LambdaWeights.raw_*`。
- **参考**：[[07-AL-PINN-增广拉格朗日]]、C 方案代码
- **实验**：Helmholtz 先验验证后移植声波。
- **风险**：max-min 交替可能不稳定。

#### Idea 8：轻量 MOO-VARI（三目标每 2k 步）
- **思路**：每 2000 步用 VARI 在 (L_PDE,L_S,L_BC) 上刷新权重，不做完整 NSGA。
- **参考**：[[08-MOO-VARI-多目标优化加权]]、[[03-DB-PINN-双层次平衡]]
- **实验**：记录 Pareto 前沿快照与最终 MSE。
- **风险**：计算量大于 ReLoBRaLo。

#### Idea 9：时间因果权 + 双快照
- **思路**：对 t>0.06 的 PDE 配点施加 Wang 因果权，抑制非物理提前波。
- **参考**：[[09-因果训练加权]]、[[10-因果注意力-CA]]
- **实验**：t=0.12 s 预测场对比；ε 与 CA 对照。
- **风险**：ε 过大导致后期时间几乎不训练。

#### Idea 10：CA 替代固定因果 ε
- **思路**：用 JCP 2026 CA 权重替换手工 ε，减少调参。
- **参考**：[[10-因果注意力-CA]]、[[09-因果训练加权]]
- **实验**：与 Idea 9 同设置 AB 测试。
- **风险**：新方法复现细节需对齐原文。

#### Idea 11：课程 + ReLoBRaLo 两阶段
- **思路**：前 30% 迭代仅强 L_S（课程），后 70% 接 ReLoBRaLo 平衡三项。
- **参考**：[[12-NeurIPS-失败模式与课程学习]]、[[04-ReLoBRaLo-相对损失平衡]]
- **实验**：复杂层状/盐丘式介质（若扩展）。
- **风险**：阶段切换点需网格搜索。

#### Idea 12：vRBA 势函数选 Φ(r)=r^p
- **思路**：在 PDE 配点实现 vRBA 一族势函数，消融 p∈{1,2,∞}。
- **参考**：[[13-vRBA-变分残差注意力]]、[[06-RBA-残差注意力]]
- **实验**：记录加权分布与 L2 误差。
- **风险**：实现需读 npj 文附录细节。

#### Idea 13：组合管线「BRDR + ReLoBRaLo + 因果」
- **思路**：空间配点 BRDR，项级 ReLoBRaLo，时间维因果权——三者分责。
- **参考**：[[01-BRDR-平衡残差衰减率]]、[[04-ReLoBRaLo-相对损失平衡]]、[[09-因果训练加权]]
- **实验**：完整 2D 声波正演；与 A/B/C 四方案对比表。
- **风险**：模块多，消融工作量大（适合一篇方法论文骨架）。
