# C 方案对比基线：五篇 PINN 损失自适应精选（2024–2026）

## 元信息

- **用途**：为 2D 声波正演 **C 方案** 筛选可直接做效果对比的 SOTA 基线
- **C 方案要点**：三项损失 \(L_{PDE}, L_S, L_{PC}\) → 梯度模长反比初始化 → λ 预训练（冻结 \(\theta\)）→ 相对进度 EMA + Softmax（降得慢 → λ 大）→ 因果时间课程
- **筛选门槛**：2024–2026 发表；CCF-A/B 或 SCI 一二区；聚焦 **项级损失权重自适应**

---

## 1. DB-PINN — 双层次损失平衡（最优先）

| 项 | 内容 |
|---|---|
| **标题** | Dual-Balancing for Physics-Informed Neural Networks |
| **发表** | IJCAI 2025（**CCF-A**） |
| **链接** | [DOI](https://doi.org/10.24963/ijcai.2025/797) · [arXiv:2505.11117](https://arxiv.org/abs/2505.11117) · [代码](https://github.com/chenhong-zhou/DualBalanced-PINNs) |
| **详细汇报** | [[2026-06-04/03-DB-PINN-双层次平衡]] |

**机制**：inter-balancing 用梯度统计平衡 PDE vs 条件项；intra-balancing 按各条件拟合难度分配权重；Welford 鲁棒更新防权重尖峰。

**对比 C 的理由**：同样是 PDE + BC/IC 多项损失；官方 benchmark 含 **Wave Equation**，与 2D 声波正演最接近。可检验 C 的「梯度初始化 + 相对进度」 vs DB 的「双层梯度/难度平衡」。

---

## 2. ReLoBRaLo — 相对损失平衡（机制最近邻）

| 项 | 内容 |
|---|---|
| **标题** | Multi-Objective Loss Balancing for Physics-Informed Deep Learning |
| **发表** | CMAME 2025, Vol.439（**SCI 一区**） |
| **链接** | [DOI](https://doi.org/10.1016/j.cma.2025.117914) · [arXiv:2110.09813](https://arxiv.org/abs/2110.09813) |
| **详细汇报** | [[2026-06-04/04-ReLoBRaLo-相对损失平衡]] |

**机制**：用 **损失相对进展**（非梯度）动态调 λ；Softmax 有界；随机 lookback 偶尔回溯到 \(L(0)\)；2025 版在 PINNacle 20+ PDE 上系统评测。

**对比 C 的理由**：C 的 `RelativeProgressLambdaWeights` 与 ReLoBRaLo **同族**。消融建议：C 去掉梯度初始化 + λ 预训练 → 近似 ReLoBRaLo；或 C 加上 random lookback → 验证两阶段设计是否值得额外算力。

---

## 3. MOO-VARI — Pareto + 方差感知相对改进

| 项 | 内容 |
|---|---|
| **标题** | A Multi-Objective Optimization Framework for Adaptive Weighting in Physics-Informed Machine Learning |
| **发表** | AAAI 2026（**CCF-A**） |
| **链接** | [DOI](https://doi.org/10.1609/aaai.v40i32.39900) |
| **详细汇报** | [[2026-06-04/08-MOO-VARI-多目标优化加权]] |

**机制**：训练嵌入 **NSGA-II** 探索 PDE/数据损失 Pareto 前沿；**VARI** 把 Pareto 方差 + 各目标相对改进转为动态 λ。

**对比 C 的理由**：C 用在线启发式调 λ；MOO-VARI 用进化搜索 + 相对改进。若 C 在 \(L_{PDE}\) vs \(L_S\) 权衡上卡住，可检验「更重 MOO」是否换到更好 Pareto 点（算力更高，适合作精度上限基线）。

---

## 4. I-PINN / IAW-PINN — 有界不确定性项级加权

| 项 | 内容 |
|---|---|
| **标题** | Improved physics-informed neural network in mitigating gradient-related failures |
| **发表** | Neurocomputing 2025（**CCF-B / SCI**） |
| **链接** | [DOI](https://doi.org/10.1016/j.neucom.2025.130167) · [arXiv:2407.19421](https://arxiv.org/abs/2407.19421) · [代码](https://github.com/PanChengN/I-PINN) |
| **详细汇报** | [[2026-06-07/03-I-PINN-有界不确定性加权]] |

**机制**：Kendall 式可学习 \(\sigma_k\)，对自适应权重设 **上界**，防止 PDE 残差权重被 BC/IC 压垮。

**对比 C 的理由**：B 方案曾出现 \(\lambda_{PDE}\) 塌缩；C 用 Softmax 单纯形（\(\sum\lambda=3\)）约束。IAW-PINN 提供另一种 **防 PDE 权重塌陷** 设计——C 的规则 λ vs IAW 的可学习 + 有界 λ。

---

## 5. ConFIG — 无冲突梯度方向（可叠加）

| 项 | 内容 |
|---|---|
| **标题** | ConFIG: Towards Conflict-free Training of Physics Informed Neural Networks |
| **发表** | ICLR 2025（**CCF-A**） |
| **链接** | [arXiv:2408.11104](https://arxiv.org/abs/2408.11104) · [项目页](https://tum-pbs.github.io/ConFIG) |
| **详细汇报** | [[2026-06-05/04-ConFIG-无冲突梯度训练]] |

**机制**：不（主要）调 λ，而是用梯度矩阵 **伪逆** 构造与各损失梯度无冲突的更新方向；M-ConFIG 降低开销。

**对比 C 的理由**：C 通过 **权重** 平衡项间贡献；ConFIG 通过 **更新方向** 消除冲突。建议：① 固定 λ=1，ConFIG vs C 全流程；② C 的 λ 调度 + ConFIG 方向修正。

## 公平对比实验建议

1. **λ 纯消融**：统一网络、步数、配点数；C 可暂时 **关掉因果课程**，只比权重机制。
2. **全方案对比**：保留 C 的因果课程（其他方法若无对应模块，在备注中说明「C 含额外时间调度」）。
3. **指标**：训练总损失曲线、达到阈值的步数、\(t=0.12s\) 的 RMSE / Rel_L2 / ACC（见 `Project/project/outputs_full/comparison_table.md`）。

## 若只要 3 篇

优先：**DB-PINN + ReLoBRaLo + I-PINN** — 分别覆盖「双层平衡」「相对进度同族」「有界可学习 λ」，与 C 三阶段设计一一可拆。
