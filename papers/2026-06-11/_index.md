## 可复现 Idea

#### Idea 1：ReLoBRaLo 消融 C 的两阶段设计（参考 [[01-C方案对比基线五篇精选]]）
- **思路**：保留 C 的网络与因果课程，仅将 λ 更新替换为 ReLoBRaLo（含 random lookback），去掉梯度初始化与 λ 预训练。
- **首个实验**：同一 full 配置；指标收敛步数、final λ、RMSE@t=0.12s。

#### Idea 2：DB-PINN inter/intra 替换 C 的 λ 规则（参考 [[2026-06-04/03-DB-PINN-双层次平衡]]）
- **思路**：Wave equation 官方 benchmark 与 2D 声波结构一致；用 DB 双层平衡替换 C 阶段 1–3 的 λ 逻辑。
- **首个实验**：对比 DB vs C 的训练曲线与 Rel_L2。

#### Idea 3：C 的 λ + ConFIG 方向（参考 [[2026-06-05/04-ConFIG-无冲突梯度训练]]）
- **思路**：λ 仍用 C 的相对进度，参数更新在 ⟨∇L_PDE, ∇L_BC⟩<0 时切换 ConFIG 伪逆方向。
- **首个实验**：叠加 vs 纯 C；看是否进一步压低 PDE 残差。
